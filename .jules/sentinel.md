## 2024-05-24 — Fix unbounded read DoS in wakeword payload parser\n**Learning:** The Wyoming protocol parser in `wakeword.py` and `wakeword_bench.py` read the `payload_length` and `data_length` from untrusted incoming JSON messages over the network and looped to read that amount of bytes without upper bounds. An attacker could specify an extremely large size and cause the application to block indefinitely attempting to read it or exhaust resources.\n**Action:** Added explicit boundaries (`> 10_000_000`) before entering the parsing loop to raise a `ValueError` for out-of-bound sizes. Also added a regression test for the large payload case.
