## 2025-02-14 — [Security] Enforce strict length bounds on untrusted Wyoming server payloads
**Learning:** The local Wyoming protocol implementation in `wakeword.py` and `wakeword_bench.py` did not enforce size bounds on network payloads. A malicious or compromised server could cause Denial of Service (DoS) by sending endless header streams without newlines, or by claiming massive `payload_length` or `data_length` fields, leading to out-of-memory (OOM) crashes via unbounded `sock.recv` loops.
**Action:** Implemented strict, defensive bounds (64KB for JSON headers, 1MB for binary data/payload frames) in the read loops and `_drain_detections` parsing logic. Added security regression tests (`tests/test_security_bounds.py`) to prevent these unbounded read vulnerabilities from returning.
