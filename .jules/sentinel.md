## 2024-05-18 — Enforce bounds on untrusted payload reading
**Learning:** Wyoming wake-word servers stream binary payloads with JSON headers. `wakeword.py` and `wakeword_bench.py` did not bounds check these header/payload dimensions. A malicious server streaming unbounded payload lengths or dropping line delimiters could DoS the client via memory exhaustion. Furthermore, silently `break`ing loop execution upon receiving truncated sockets led to outer loops attempting to parse the truncated blocks.
**Action:** Replaced missing chunk handling in socket read loops with bounds checks: max header of 64KB (65536 bytes) and max payload of 1MB (1048576 bytes) across both files. Reverted `raise ConnectionError` to `break`/`return` for empty socket reads to avoid crashing the background listener threads upon clean server disconnects, as identified during code review.
