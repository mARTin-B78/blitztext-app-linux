## 2025-02-18 — Enforce size bounds on Wyoming protocol parsing
**Learning:** Untrusted network streams, like those from the Wyoming protocol, require strict bounds on both newline-framed JSON headers and separately sent binary payloads to prevent Denial of Service (DoS). `len(line)` checks guard against unbounded `\n` search, and validating `data_length` and `payload_length` fields explicitly stops massive memory allocations. We must enforce hard failure limits (`break` or `return` rather than soft-truncating with `min()`) for memory safety while retaining clean socket disconnections.
**Action:** Implemented hard boundary checks (64KB for headers, 1MB for payloads) within socket parsing loops of `wakeword.py` (`WakewordListener` and `WakewordActionListener`) and `wakeword_bench.py` (`_drain_detections`).
