## 2026-07-15 — [Untrusted Parsing Bounds in Wyoming Network Protocol]
**Learning:** Network protocols that parse frames (e.g. Wyoming JSON headers and binary payloads) without explicit bounds are vulnerable to Denial of Service (DoS) attacks via unbounded memory accumulation. Malicious or malformed inputs without delimiters can exhaust memory resources, breaking application stability.
**Action:** Implemented strict memory bounding within `linux/blitztext/wakeword.py` (64KB max header size, 1MB max data/payload lengths) and `linux/blitztext/wakeword_bench.py` (buffer limiting `buf > 1048576 + 65536`) to safeguard against these untrusted inputs without hampering standard communication. Also, ensure EOF handling uses `return` instead of `break` to avoid crashes from partial buffer parsing.
## 2026-07-15 — [Missing Dependencies for PyGObject in CI]
**Learning:** PyGObject 3.56+ compilation on Ubuntu 24.04 requires `libgirepository-2.0-dev`, `pkg-config`, and `build-essential` in addition to the standard dependencies. If missing, PyGObject installation fails due to unmet system dependencies when run in constrained environments like GitHub Actions CI.
**Action:** Appended `libgirepository-2.0-dev pkg-config build-essential` to the `apt-get install` command list inside the `.github/workflows/ci.yml` file to ensure the CI build correctly provisions the required libraries for `PyGObject`.
